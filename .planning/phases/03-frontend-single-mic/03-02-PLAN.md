```typescript
interface PresencialTranscriptionProps {
  transcriptions: TranscriptionSegment[];

  patientName?: string;
  // New props for single-mic mode:

}
```

**Changes -- backward compatible (D-03, dual-mic mode unchanged):**

1. **UNKNOWN speaker styling (D-15):** Add a new CSS class `.unknown` for transcription items where `speaker === 'UNKNOWN'`. Style: background `#F3F4F6`, border-left `#9CA3AF` (gray), generic speaker icon (use `MessageCircle` from lucide-react). Label shows "Processando..." or "Aguardando diarizacao...".

2. **Speaker ID display (D-18 pre-mapping):** When `micMode === 'single'` and transcription has `participantId` of 'speaker_0' or 'speaker_1' but no mapping yet (`speakerMapping` is null), show label as "Speaker 0" / "Speaker 1" with blue/green colors respectively.

3. **Mapped label display (D-18, D-19 post-mapping):** When `speakerMapping` is provided, resolve participantId 'speaker_0'/'speaker_1' to the mapped role. If speaker_0 maps to 'doctor', show as "Medico" with blue styling. If maps to 'patient', show as "Paciente" with green styling. Use the `speakerMapping` prop directly -- no refetch needed per D-19.

4. **Smooth transitions (D-17):** Wrap the transcription list items in framer-motion `AnimatePresence` with `mode="popLayout"`. Each item is a `motion.div` with:
   - `initial={{ opacity: 0, y: 10 }}`
   - `animate={{ opacity: 1, y: 0 }}`
   - `exit={{ opacity: 0, y: -10 }}`
   - `transition={{ duration: 0.3 }}`
   This handles the fade out of gray UNKNOWN items and fade in of colored diarized items.

5. **Backward compatibility (D-03):** When `micMode` is 'dual' or undefined, render exactly as before (existing doctor/patient logic unchanged). The new logic only activates when `micMode === 'single'`.

6. **Rendering logic for single-mic mode:**

   - If `speaker === 'MEDICO'` or `speaker === 'PACIENTE'` (from dual mode or after full resolution): existing blue/green styling
   - If `participantId` is 'speaker_0' or 'speaker_1' and `speakerMapping` exists: resolve to MEDICO/PACIENTE and use corresponding styling
   - If `participantId` is 'speaker_0' or 'speaker_1' and no mapping: show "Speaker 0"/"Speaker 1" with muted blue (#6B8DAF)/green (#6EE7B7) styling
