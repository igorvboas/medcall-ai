```sql
CREATE OR REPLACE FUNCTION append_transcription_text(
  p_consultation_id UUID,
  p_text TEXT
)
RETURNS VOID
LANGUAGE plpgsql
AS $$
BEGIN
  INSERT INTO transcriptions (consultation_id, raw_text, language, model_used, created_at)
  VALUES (p_consultation_id, p_text, 'pt-BR', 'whisper-1-vad', NOW())
  ON CONFLICT (consultation_id)
  DO UPDATE SET
    raw_text = CASE
      WHEN transcriptions.raw_text IS NULL OR transcriptions.raw_text = ''
      THEN EXCLUDED.raw_text
      ELSE transcriptions.raw_text || E'\n' || EXCLUDED.raw_text
    END,
    updated_at = NOW();
END;
$$;

GRANT EXECUTE ON FUNCTION append_transcription_text TO service_role;
```

**File 1: `finalize_consultation.sql`** (per D-10, D-11, D-12)

Create a `plpgsql` function `finalize_consultation` with these exact parameters:
- `p_consultation_id UUID` -- the consultation to finalize
- `p_transcription TEXT` -- transcription text to copy to consultations.transcricao
- `p_status TEXT DEFAULT 'COMPLETED'` -- target status
- `p_duration_minutes NUMERIC DEFAULT NULL` -- consultation duration in minutes (float)
- `p_call_session_room_id TEXT DEFAULT NULL` -- room_id for call_sessions update (optional)

Returns `BOOLEAN` (true on success).

The function body performs these writes in a single transaction:
1. `UPDATE consultations SET transcricao = p_transcription, status = p_status, consulta_finalizada = true, consulta_fim = NOW(), duracao = p_duration_minutes, updated_at = NOW() WHERE id = p_consultation_id;`
2. Only if `p_call_session_room_id IS NOT NULL`: `UPDATE call_sessions SET status = 'ended', ended_at = NOW(), webrtc_active = false WHERE room_id = p_call_session_room_id;`

Add `EXCEPTION WHEN OTHERS THEN RAISE;` to re-raise and trigger rollback.

End with: `GRANT EXECUTE ON FUNCTION finalize_consultation TO service_role;`

Per D-12: webhook_deliveries is NOT part of this transaction.
