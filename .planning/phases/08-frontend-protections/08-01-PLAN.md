    Constants at top of file:
    - `SILENCE_THRESHOLD_MS = 30000` (per D-08)
    - `SILENCE_CHECK_INTERVAL_MS = 1000` (per D-08)

    Three `useEffect` blocks inside the hook:

    1. **track.onended detection** (per D-01): When `stream` changes, get all audio tracks via `stream.getAudioTracks()`. Add `ended` event listener on each track that calls `setIsMicConnected(false)`. On mount, also check `track.readyState === 'ended'` for tracks already dead. Cleanup: remove event listeners. Do NOT stop recording automatically per D-04.

    2. **devicechange fallback** (per D-02): Listen to `navigator.mediaDevices.addEventListener('devicechange', handler)` — NOT the property setter (anti-pattern from research). Handler: enumerate devices, filter `audioinput`, check if `activeTrack.getSettings().deviceId` is still present. If not present, set `isMicConnected(false)`. If present and track readyState is `live`, set `isMicConnected(true)` (auto-recovery when mic reconnected — per D-03 banner auto-dismiss).

    3. **Silence detection** (per D-06, D-08, D-09): Only runs when `stream` is non-null AND `isRecording` is true. Create a NEW `VoiceActivityDetector(stream)` instance (per research: own instance is simpler, 2 AudioContexts is safe). Use `setInterval` at 1000ms. Each tick: call `vadRef.current.isSpeaking()`. If speaking, reset `silenceStartRef.current = null` and `setSilenceDurationMs(0)`. If not speaking, if `silenceStartRef.current` is null set it to `Date.now()`, then `setSilenceDurationMs(Date.now() - silenceStartRef.current)`. When `isRecording` becomes false, reset silence state and destroy VAD. Cleanup: `clearInterval` + `vadRef.current?.destroy()`.

    Computed return: `isSilent: silenceDurationMs >= SILENCE_THRESHOLD_MS`.

    Use `'use client'` directive at top. Import from `@/lib/audioUtils`.

    Hook signature: `useBeforeUnloadProtection(isRecording: boolean, onFlush?: () => void): void`

    Use a `useRef` for `onFlush` to avoid stale closures (update ref on every render).

    Single `useEffect` depending on `[isRecording]`:
    - If `!isRecording`, return early (no listener registered)
    - Create handler: `(event: BeforeUnloadEvent) => { onFlushRef.current?.(); event.preventDefault(); event.returnValue = ''; }`
    - `window.addEventListener('beforeunload', handler)`
    - Cleanup: `window.removeEventListener('beforeunload', handler)`

    Note per research pitfall 1: The flush callback is best-effort. Phase 5 incremental save already persists data every ~5s. This is a last-chance save.

    Use `'use client'` directive at top.
